# Acorn Words

A small reading game for kindergartners, built as a single web page.

- **Flash cards** on handwriting-paper lines, with an example sentence for each word
- **Hear & find**: listen to a word, then tap it
- **Finish the sentence**: pick the word that fills the blank
- **Sound slide**: blend short words sound by sound, and look inside sight words to find their "heart" (tricky) parts

Grown-ups can change the word list from the page. Progress is saved only in the browser on that device.

No build step: open `index.html` in a browser.
